一、 软件定位与核心理念

VaultGuard（密码保险箱 - 离线版） 是一款专为极致隐私和数据自主掌控而设计的纯本地单机高安全密码与两步验证（2FA/TOTP）管理器。

在云端泄露事件与第三方数据收集日益频繁的今天，VaultGuard 坚持“物理零网络（Zero-Network）”与“零知识证明（Zero-Knowledge）”原则：

  • 物理切断网络：应用在 AndroidManifest.xml 清单中彻底剔除并阻断了 android.permission.INTERNET 与 android.permission.ACCESS_NETWORK_STATE 网络权限，无任何后台服务器、无远程 API、无分析追踪代码。
  • 本地硬件加密：主加密密钥由用户自主掌握的主密码通过 Argon2id 算法派生，并在设备安全硬件芯片（Android Keystore / TEE / StrongBox）保护下对所有数据进行 XChaCha20-Poly1305 / AES-256-GCM 工业级强加密。
  • 全主权数据掌控：所有数据均只保留在您手持设备的本地加密数据库中，除了掌握主密码的您本人，任何人（包括开发者）都无法解密或窥探。

二、 核心功能特性

  1. 四维凭据类型支持：
    • 常规账号密码：支持标题、登录用户名/邮箱、安全密码以及专属的 3 项自定义备注（备注1、备注2、备注3）。
    • API 密钥与服务 Token：专为开发者与极客设计，便捷管理 OpenAI、AWS、GitHub 等各种生产 API 密钥与端点。
    • 密保助记词（Mnemonic Phrases）：安全存储区块链钱包、加密资产的 12/24 位英文助记词，支持自动切词分块卡片展示。
    • 两步动态验证码（TOTP/2FA）：基于 RFC 6238 标准的 30 秒动态令牌发生器，支持毫秒级时间进度圆环、一键复制验证码、相机直接扫码与相册图片解析导入。
  2. 高熵密码生成器：内置高熵生成引擎，支持大写字母、小写字母、数字及特殊符号组合，最长支持 64 位，并实时计算比特熵（Entropy bits）。
  3. 系统级自动填充（Autofill Service）：无缝集成 Android 原生自动填充框架，在网页或其他 App 登录时，经生物识别或主密码授权后秒级填入凭据。
  4. 灵活的双轨备份与灾备：
    • 加密数据库备份：导出受独立保护密码保护的 .vgvault 加密文件，可在新设备上安全恢复。
    • 通用 CSV 导入导出：支持与 Chrome、Bitwarden、KeePass 等工具无缝兼容的 CSV 数据互导。
  5. 生物识别快速解锁：兼容设备指纹与面容解锁（BiometricPrompt），兼顾安全与便利。

三、 详细使用操作指南

步骤 1 首次初始化保险箱

1. 打开应用，系统展示“开启您的加密空间”初始化界面；
2. 设置主密码：长度至少 10 位，必须同时包含大写字母、小写字母、数字和特殊符号，无空格；
3. 再次确认主密码并勾选同意条款，点击“生成加密数据库”。

⚠️ 核心安全警示 纯本地零知识架构无任何云端服务器，主密码一旦遗失将永久无法找回或重置！请务必牢记主密码，建议抄写在纸质介质上安全存放。
步骤 2 日常解锁与生物识别

- 主密码解锁：输入主密码，点击“解锁保险箱”；
- 指纹/面容解锁：在“我的/设置”中开启“生物识别快速解锁”，之后即可一秒秒开；
- 即时锁定：点击“锁定保险箱”，或退到后台超时后，应用自动清除内存密钥并锁定。

步骤 3 添加与管理凭据（含三级备注）

1. 点击主界面右下角悬浮按钮 “+”；
2. 选择类型（常规密码、API 密钥、助记词、或 TOTP 两步验证）；
3. 填写标题、账户、密码（或点击“🎲 一键生成”快速派生 16 位高强密码）；
4. 三级自定义备注：
  • 备注1：可填写官方网址、登录入口或主域名；
  • 备注2：可填写关联备用网址、备选服务或平台备忘；
  • 备注3：可填写安全问题答案、交易 PIN 码、备用手机等附加信息；
5. 点击“保存新记录”即可安全加密落盘。

步骤 4 两步动态验证码（TOTP）的导入与使用

- 扫码导入：添加时切换至“扫码识别密钥”，支持相机直接扫描网页二维码，或点击“🖼️ 从相册导入图片”识别；
- 手动输入：支持直接输入 Base32 格式密钥；
- 动态令牌：在底部导航“验证”页面每 30 秒自动刷新，点击验证码直接复制。

步骤 5 系统自动填充配置

进入手机系统“设置” → “语言和输入法” → “自动填充服务”，选择“安全密码箱自动填充”。在登录其他 App 或浏览器时，轻触输入框即可通过指纹验证一键填入账号密码。

步骤 6 数据备份、恢复与换机迁移

换机推荐：加密备份恢复
1. 在“我的”页面点击“导出加密备份”，设置专属备份保护密码，保存 .vgvault 文件；
2. 通过有线、蓝牙或离线介质传到新手机，在新机上打开本应用点击“导入加密备份”，输入备份密码即可完美复原。

四、 常见问题解答 (FAQ)

Q1：应用真的没有任何网络通信吗？

是的。本应用在系统清单中彻底剥离了 android.permission.INTERNET 权限。不论您的手机是否开启 Wi-Fi 或移动数据，操作系统底层都会直接禁止本应用发起任何网络调用。

Q2：如果我忘记了主密码，开发者能帮我恢复吗？

绝对无法恢复。本应用遵循零知识证明架构，所有加密密钥均由主密码在设备内存实时派生，开发者与任何第三方均不持有密钥。遗忘密码后任何人都无法解密。

Q3：换手机时如何迁移密码数据？

在旧手机“我的”页面点击“导出加密备份”，将生成的加密文件传到新手机，在新手机上点击“导入加密备份”并输入导出时设定的保护密码即可完成全量迁移。

1. Product Overview & Core Philosophy

VaultGuard (Offline Edition) is an ultra-secure, standalone Password & Two-Factor Authentication (2FA/TOTP) Manager engineered for users who demand absolute data sovereignty and uncompromising privacy.

In an era of recurring cloud breaches and pervasive telemetry, VaultGuard adheres strictly to Physical Zero-Network Isolation and Zero-Knowledge Architecture:

  • Physical Network Sandbox: All network permissions (android.permission.INTERNET and android.permission.ACCESS_NETWORK_STATE) have been completely stripped from the application manifest. The OS physically prevents any network socket connections.
  • Hardware-Backed Encryption: Master encryption keys are derived on-device from your master password using Argon2id. All data is protected with XChaCha20-Poly1305 / AES-256-GCM authenticated ciphers and anchored by the Android Keystore (TEE / StrongBox).
  • Absolute Data Ownership: All credentials remain strictly within your device's local encrypted SQLite database. No one—including the developer—has access to your data.

2. Key Features

  1. Four Versatile Credential Types:
    • Logins & Passwords: Store titles, usernames/emails, passwords, and 3 custom note fields (Note 1, Note 2, Note 3).
    • API Keys & Tokens: Designed for developers to manage OpenAI, AWS, GitHub, and cloud API keys.
    • Mnemonic Phrases: Securely store 12/24-word recovery seeds for cryptocurrency wallets with chunked visual cards.
    • 2FA / TOTP Authenticator: RFC 6238 compliant 30-second token generator with real-time countdown ring, single-tap copy, camera scanning, and album QR decoding.
  2. High-Entropy Password Generator: Cryptographically secure pseudorandom generator supporting uppercase, lowercase, numbers, and symbols up to 64 characters with real-time entropy calculation.
  3. System Autofill Integration: Native Android Autofill Service fills credentials into browsers and external apps instantly after biometric verification.
  4. Dual Backup & Migration Channels:
    • Encrypted Vault Backup: Password-protected .vgvault encrypted files for secure cold storage and migration.
    • Universal Plaintext CSV: Import/export standard CSV files compatible with Bitwarden, KeePass, and Chrome.
  5. Biometric Quick Unlock: Fingerprint and facial recognition unlock via Android BiometricPrompt APIs.

3. Step-by-Step Instructions

Step 1 Initial Vault Setup

1. Launch the application to open the "Setup Your Encrypted Vault" screen;
2. Create Master Password: At least 10 characters, containing uppercase, lowercase, digits, and special symbols, without spaces;
3. Confirm your password, accept terms, and tap "Create Encrypted Vault".

⚠️ Critical Warning VaultGuard is a 100% offline, zero-knowledge app. If you lose your master password, your data cannot be recovered by anyone! Keep a written offline copy in a safe location.
Step 2 Unlocking & Biometrics

- Password Unlock: Enter your master password and tap "Unlock Vault";
- Biometric Unlock: Enable "Biometric Unlock" in settings to unlock instantly using fingerprint or face;
- Locking: Tap "Lock Vault" in settings or background the app to trigger automatic memory-clearing and lock.

Step 3 Adding & Managing Credentials (with Notes 1/2/3)

1. Tap the floating "+" button on the vault dashboard;
2. Select the credential type;
3. Enter Title, Account, and Secret (or tap "🎲 Generate" for a quick 16-character secure password);
4. Three Custom Notes:
  • Note 1: Website, login URL, or primary portal;
  • Note 2: Secondary endpoint or platform description;
  • Note 3: Security answers, PINs, or recovery info;
5. Tap "Save Record" to persist with local hardware encryption.

Step 4 Using TOTP Two-Factor Authenticator

- Scan QR: Switch to "Scan QR Code" to capture using camera or pick an image from your photo album;
- Manual Key: Paste any standard Base32 secret string;
- Dynamic Codes: View 30-second refreshing tokens in the "2FA" tab; tap to copy.

Step 5 Configuring System Autofill

Go to Android Settings → Languages & input → Autofill service, and select VaultGuard Autofill. Tap credential fields in any app to authenticate with biometrics and fill credentials instantly.

Step 6 Backup, Restore & Migration

Recommended: Encrypted Backup
1. Open Settings → tap "Export Encrypted Backup", set a dedicated backup password, and save the .vgvault file;
2. Transfer the file to your new device, open VaultGuard, tap "Import Encrypted Backup", and enter the backup password.

4. Frequently Asked Questions (FAQ)

Q1: Does this app really have zero network access?

Yes. The android.permission.INTERNET permission is completely removed from the manifest. The Android OS prohibits any network connection regardless of Wi-Fi or cellular state.

Q2: If I forget my Master Password, can the developer help me recover my data?

No, it is technically impossible. VaultGuard operates on zero-knowledge principles. Encryption keys are derived only in memory on your physical device. No backdoors or recovery keys exist.

Q3: How do I transfer my vault to a new phone?

Export an "Encrypted Backup" on the old phone, move the encrypted file via USB or Bluetooth to the new phone, and import it using your backup password.
